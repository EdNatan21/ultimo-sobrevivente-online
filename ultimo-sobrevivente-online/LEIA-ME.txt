ÚLTIMO SOBREVIVENTE — MULTIPLAYER v0.6.2

EXECUTAR LOCALMENTE
1. Instale Node.js 20 ou superior.
2. Abra o terminal na pasta que contém package.json.
3. Execute: npm install
4. Execute: npm start
5. Acesse: http://localhost:3000

TESTES
- Execute: npm test

PUBLICAR NO RENDER
- Root Directory: pasta que contém package.json (deixe vazio se estiver na raiz do repositório).
- Build Command: npm install
- Start Command: npm start
