ÚLTIMO SOBREVIVENTE — MULTIPLAYER v0.5

1. Instale Node.js 20 ou superior.
2. Abra o terminal nesta pasta.
3. Execute: npm install
4. Execute: npm start
5. Acesse: http://localhost:3000

RENDER
- Build Command: npm install
- Start Command: npm start
- Root Directory: informe a pasta que contém package.json. Se package.json estiver na raiz do repositório, deixe vazio.

NOVIDADES v0.5
- Itens com efeitos próprios nas cenas.
- Opção D especial condicionada ao item necessário.
- Ações de tiro aparecem somente para quem possui pistola.
- Munição é consumida ao atirar; sinalizadores são consumidos em ações furtivas.
- Colete absorve uma falha e é consumido ao proteger o jogador.
- Anfitrião escolhe a dificuldade dos zumbis no lobby; isso altera as probabilidades junto com a progressão da campanha.
- Anfitrião pode encerrar a campanha a qualquer momento.

Consulte README.md para regras detalhadas e atualização do GitHub/Render.


Versão 0.6: resultados reorganizados; escolhas confirmadas visíveis; descrições de recompensas; justificativa de eliminações; desempates exibidos rodada a rodada; limite de 70% nas chances; dificuldade progressiva; avanço automático quando todos os participantes, inclusive eliminados, confirmam.
