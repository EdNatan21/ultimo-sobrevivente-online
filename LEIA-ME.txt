ÚLTIMO SOBREVIVENTE — MULTIPLAYER v0.4

Esta versão integra a interface ao servidor Socket.IO. Não é mais apenas uma infraestrutura de salas.

RODAR LOCALMENTE:
1. Instale Node.js 20 ou superior: https://nodejs.org/
2. Abra um terminal nesta pasta.
3. Execute: npm install
4. Execute: npm start
5. Abra http://localhost:3000

PUBLICAR PARA JOGAR COM AMIGOS:
1. Envie todos os arquivos para um repositório GitHub.
2. No Render, crie um Web Service conectado ao repositório.
3. Build Command: npm install
4. Start Command: npm start
5. Publique e compartilhe o endereço HTTPS criado pelo Render.

ARQUIVOS:
- server.js: servidor multiplayer e regras autoritativas.
- game-data.js: cenas, atributos e itens compartilhados.
- public/index.html: interface do jogo.

MODO DE JOGO:
- Salas privadas por código, 2 a 8 pessoas.
- Distribuição individual de atributos.
- Escolhas simultâneas e resultados sincronizados.
- Resolução das probabilidades e disputa de itens no servidor.
- Confirmação de todos os sobreviventes antes de avançar.
- Sem bots no fluxo principal.

Limitação: salas são mantidas em memória. Se o servidor reiniciar, as partidas em andamento são encerradas.
